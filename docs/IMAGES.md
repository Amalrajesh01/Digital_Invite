# Imagery guide

The demo weddings use **illustrations generated by `scripts/demo/art.ts`** (procedural SVG rendered to WebP) so the
repository ships with no licensed photography. For real weddings, upload real or AI-generated images through the
**Media library** (Studio → wedding → Gallery, or any image field in the wizard/editor) — they are validated,
re-encoded to WebP, stripped of EXIF/GPS and served in four sizes automatically.

## Brand & marketing images (for the landing page / social)

Generate at the sizes below with your image tool of choice, then drop them in `public/brand/` and reference them from
`src/app/page.tsx`. Keep the StackBridge look: deep navy `#0b1b35`, blue `#3056d3` / `#4a6cf7`, cool white `#f5f7fb`.

| Slot | Size | Prompt idea |
|---|---|---|
| Landing hero backdrop | 2400×1400 | "Soft abstract navy-to-blue gradient with faint geometric hexagon grid, subtle depth, no text, premium software brand" |
| Social share image | 1200×630 | Already generated: `public/brand/og-image.jpg` (`node scripts/brand-assets.mjs`) |

## Wedding imagery (per couple — upload in the Media library)

| Slot | Ratio | Prompt idea (replace details with the couple's culture and venue) |
|---|---|---|
| Hero / cover | 3:4 | "Editorial wedding illustration, couple silhouetted at sunset by backwaters, warm light, palm trees, oil lamps, no text" |
| Bride / groom portraits | 3:4 | Real photographs are best; illustrated portraits should be gender-appropriate and culturally accurate |
| Story chapters | 4:3 | One image per moment (first meeting, proposal, engagement) in a consistent style |
| Venue | 16:9 | Exterior/hall of the actual venue; a real photograph is preferable to AI here |
| Event cards | 1:1 | Haldi, mehendi, muhurtham, sadhya — one consistent illustrated set |
| Dress-code palette | — | Uses colour swatches, no image needed |
| Open-graph (WhatsApp preview) | 1.91:1 | 1200×630 with the couple's names; set in the editor's "Sharing preview" |

Tips: keep faces of real family members as real photographs; use AI imagery for backgrounds, textures and illustrated
scenes; always write alt text (editor → media → alt) for accessibility.
