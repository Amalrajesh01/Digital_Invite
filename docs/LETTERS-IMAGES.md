_Generated by `npm run docs:letters`. Source of truth: `src/domain/letters/images.ts`. Checked by `npm run letters:check`._

Every photograph is bundled (never hot-linked), processed by `npm run letters:images` into a 2:3 crop on its focal point, and listed here with its licence, its description and everywhere it is used. A real letter always uses its sender's own photographs for anything personal; these supply atmosphere and stand in for a couple in the public demonstrations only. Photographs marked **people** show someone who can be recognised and are never the backdrop of a closure experience.
